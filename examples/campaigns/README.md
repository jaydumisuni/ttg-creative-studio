# Editable Creative Studio campaign samples

These are original procedurally composed illustrations, not AI-generated images or manufacturer product photographs. All three use Studio's real layer schema, renderer and export service.

Open each campaign.ttgstudio.json in Creative Studio using File > Open Project. Its assets/ folder must stay beside it. The portable-campaign.zip contains the project, assets, PNG and SHA-256 manifest and can be extracted elsewhere.

Choose Design Campaign to create new layouts with your own headlines, colors and optional product image. The images and editable project are generated locally without Hunter, Ptah or an image-generation API.
